# Использование микросервиса

```
ai-service/
├── main.py              # FastAPI приложение
├── ai_agent.py          # Логика работы с OpenAI API
├── models.py            # Pydantic модели
├── requirements.txt     # Зависимости
├── Dockerfile          # Docker конфигурация
└── .env.example        # Пример файла с переменными окружения
```

### ai_agents.py - Содержит в себе логику обращения к чатботам

- GeminiAIAgent  - класс для работы с чатботом Gemini
- build_user_prompt - функция для объеденения данных пользователя и промптов задаы

Далее в файле идут системные промпты и промпты для задач

### main.py - Содержит в себе все эндпоинты которые работают с задачами
